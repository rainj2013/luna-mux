# Luna Mux v0.5.5

新增受管浏览器代理设置，方便需要通过代理访问网站的用户在 Luna Mux 中配置网络连接，并调整 Browser 页面的设置布局。

### 新增与改进

- **浏览器代理**：Browser 页面新增代理地址输入框，支持 HTTP、HTTPS、SOCKS4 和 SOCKS5。配置按项目会话保存，留空时使用系统网络设置。
- **启动时应用代理**：手动启动和 Agent 自动启动的受管浏览器都会使用保存的代理。修改后在下次启动时生效，已经运行的浏览器需要重启。
- **浏览器设置布局**：代理和浏览器配置并排展示，代理地址使用紧凑输入框，保存按钮紧邻输入框；窄窗口下自动改为上下排列。

### 安装包说明

- macOS 提供 Intel（x64）和 Apple Silicon（arm64）DMG。
- Windows 用户建议优先选择标准版。Windows 11 和大部分 Windows 10 已内置 WebView2，可直接安装使用。
- Windows with-webview2 离线版仅建议系统未预装 WebView2，或需要在特殊离线环境中安装时使用。
